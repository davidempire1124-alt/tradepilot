# TradePilot — free-hosted trading dashboard prototype

This is a mobile-first static prototype inspired by the layout and workflow shown in the supplied reference video.

## Included
- Dashboard with quick-action cards
- Speed Bot page
- Bulk Trading analysis simulator
- Bot Builder
- Local JSON config export
- No paid libraries or external services
- No live trading or broker credentials

## Free deployment
Upload `index.html`, `style.css`, `app.js`, and `README.md` to a GitHub repository and enable GitHub Pages.

Your free address will be:
`https://YOUR-USERNAME.github.io/YOUR-REPOSITORY/`

A custom domain is optional and normally requires owning a domain. The GitHub Pages address itself is free.

## Important
The analysis is a simulator. Before connecting real-money trading, add authentication, server-side secret handling, rate limits, audit logs, risk controls, and a broker API only after checking that the broker permits automated trading.
